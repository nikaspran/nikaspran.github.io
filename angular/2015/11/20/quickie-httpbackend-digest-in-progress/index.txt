<p>When <code>flush()</code> and <code>verifyNoOutstandingExpectation()</code> <code>$httpBackend</code> methods are used together,
Angular mistakenly tries to do a double $digest if there's an error in one of your expectations,
which results in messy errors like this:</p>

<p>The second stacktrace is less than helpful and mostly entirely misleading.
This usually happens if you have a unit testing (either mocha or jasmine) setup similar to this:</p>
<pre><code class="hljs language-js">angular.<span class="hljs-title function_">module</span>(<span class="hljs-string">'myApp'</span>).<span class="hljs-title function_">service</span>(<span class="hljs-string">'service'</span>, <span class="hljs-keyword">function</span> (<span class="hljs-params">$http</span>) {

    $http.<span class="hljs-title function_">get</span>(<span class="hljs-string">'http://www.example.com2'</span>); <span class="hljs-comment">// &#x3C;-- BUG HERE</span>
  };
});
</code></pre>
<pre><code class="hljs language-js"><span class="hljs-title function_">describe</span>(<span class="hljs-string">'service'</span>, <span class="hljs-keyword">function</span>(<span class="hljs-params"></span>){
  <span class="hljs-keyword">var</span> service;

  <span class="hljs-title function_">beforeEach</span>(<span class="hljs-comment">/*... setup and inject everything ...*/</span>);

  <span class="hljs-title function_">afterEach</span>(<span class="hljs-keyword">function</span>(<span class="hljs-params"></span>){
    $httpBackend.<span class="hljs-title function_">verifyNoOutstandingExpectation</span>();
    $httpBackend.<span class="hljs-title function_">verifyNoOutstandingRequest</span>();
  });

  <span class="hljs-title function_">it</span>(<span class="hljs-string">'should work'</span>, <span class="hljs-keyword">function</span> (<span class="hljs-params"></span>) {
    $httpBackend.<span class="hljs-title function_">whenGET</span>(<span class="hljs-string">'http://www.example.com'</span>).<span class="hljs-title function_">respond</span>(<span class="hljs-number">200</span>);
    service.<span class="hljs-title function_">doCall</span>();
    $httpBackend.<span class="hljs-title function_">flush</span>();
  });

</code></pre>
<p>This setup here is in fact what the <a href="https://docs.angularjs.org/api/ngMock/service/$httpBackend">official Angular documentation</a>
recommends when using <code>$httpBackend</code>, but it doesn't behave very well.</p>
<p>This happens because both <a href="https://github.com/angular/angular.js/blob/master/src/ngMock/angular-mocks.js#L1724">$httpBackend.verifyNoOutstandingExpectation()</a> and <a href="https://github.com/angular/angular.js/blob/master/src/ngMock/angular-mocks.js#L1692">$httpBackend.flush()</a> both have <code>$rootScope.$digest()</code> in them. When an error happens, the <code>$digest</code>
from the <code>flush()</code> still hasn't ended by the time the <code>afterEach</code> block hits and you get the misleading
<code>Error: [$rootScope:inprog] $digest already in progress</code> message.</p>
<p>Here's the <code>verifyNoOutstandingExpectation()</code> method:</p>
<pre><code class="hljs language-js">$httpBackend.<span class="hljs-property">verifyNoOutstandingExpectation</span> = <span class="hljs-keyword">function</span>(<span class="hljs-params">digest</span>) {
  <span class="hljs-keyword">if</span> (digest !== <span class="hljs-literal">false</span>) $rootScope.$digest();
  <span class="hljs-keyword">if</span> (expectations.<span class="hljs-property">length</span>) {
    <span class="hljs-keyword">throw</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">Error</span>(<span class="hljs-string">'Unsatisfied requests: '</span> + expectations.<span class="hljs-title function_">join</span>(<span class="hljs-string">', '</span>));
  }
};
</code></pre>
<p><a id="solution"></a>
As we can see, there's an optional undocumented parameter called <code>digest</code>. To fix
the issue, call the method with <code>false</code> to make it skip the unnecessary <code>$digest</code> cycle:</p>
<pre><code class="hljs language-js"><span class="hljs-title function_">afterEach</span>(<span class="hljs-keyword">function</span>(<span class="hljs-params"></span>){
  $httpBackend.<span class="hljs-title function_">verifyNoOutstandingExpectation</span>(<span class="hljs-literal">false</span>); <span class="hljs-comment">// &#x3C;-- no unnecessary $digest</span>
  $httpBackend.<span class="hljs-title function_">verifyNoOutstandingRequest</span>();
});
</code></pre>
