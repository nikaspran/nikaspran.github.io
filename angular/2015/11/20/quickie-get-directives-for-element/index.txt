11:Tc4e,<p>Unfortunately, this is not entirely trivial. I'd love to give you a snippet you can paste into console,
but so far this is the best I've come up with. Anyhow, here's a way to inspect the directives of an element:</p>
<p>Set a breakpoint in the <code>compileNodes()</code> function in the Angular source somewhere
after the <code>collectDirectives()</code> method call:</p>
<img src="/images/quickie-get-directives-for-element/breakpoint.png">
<p>Then paste the following into your console:</p>
<pre><code class="hljs language-js">el = <span class="hljs-variable language_">document</span>.<span class="hljs-title function_">querySelector</span>(<span class="hljs-string">'&#x3C;your element selector>'</span>); <span class="hljs-comment">//get your element somehow</span>
angular.<span class="hljs-title function_">element</span>(<span class="hljs-variable language_">document</span>.<span class="hljs-property">body</span>).<span class="hljs-title function_">injector</span>().<span class="hljs-title function_">get</span>(<span class="hljs-string">'$compile'</span>)(angular.<span class="hljs-title function_">element</span>(el));
</code></pre>
<p>You'll be able to see the directives in result of the <code>collectDirectives()</code> method call,
which the non-minified case will be <code>directives</code>:</p>
<pre><code class="hljs language-js"><span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(directives);

    {
      <span class="hljs-string">"restrict"</span>: <span class="hljs-string">"A"</span>,
      <span class="hljs-string">"controllerAs"</span>: <span class="hljs-string">"ctrl"</span>,

  ]
</code></pre>
<p>You can also get a list of all the directives registered on the current <code>$injector</code>,
which is usually going to be all the directives in your app:</p>
<pre><code class="hljs language-js"><span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(hasDirectives);
> [<span class="hljs-comment">/* all directives registered on the $injector */</span>]
</code></pre>
<p>Obviously this is going to be a little trickier if you're working with minified code
but the same principles apply and you can work out the equivalent variables to query.</p>
