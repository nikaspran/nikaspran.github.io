11:Tb35,<p>Sometimes, you want to optionally wait for a promise before performing some synchronous code.
The most obvious solution unfortunately leads to some duplication:</p>
<pre><code class="hljs language-js"><span class="hljs-keyword">function</span> <span class="hljs-title function_">onExit</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">if</span> (hasChanges) {
    <span class="hljs-title function_">showConfirmationModal</span>()
      .<span class="hljs-title function_">then</span>(<span class="hljs-function">() =></span> <span class="hljs-title function_">goToHomePage</span>());
  } <span class="hljs-keyword">else</span> {
    <span class="hljs-title function_">goToHomePage</span>();
  }
}
</code></pre>
<p>The more complicated a flow gets, the more unwieldy it becomes.
A good way of dealing with this is by introducing what I sometimes call a <em>maybePromise</em>:</p>
<pre><code class="hljs language-js"><span class="hljs-keyword">function</span> <span class="hljs-title function_">onExit</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">const</span> maybeConfirmExit = hasChanges ? <span class="hljs-title function_">showConfirmationModal</span>() : <span class="hljs-title class_">Promise</span>.<span class="hljs-title function_">resolve</span>();
  maybeConfirmExit.<span class="hljs-title function_">then</span>(<span class="hljs-function">() =></span> <span class="hljs-title function_">goToHomePage</span>());
}
</code></pre>
<p>This can really simplify more complicated flows which include more than one optional gate:</p>
<pre><code class="hljs language-js"><span class="hljs-keyword">function</span> <span class="hljs-title function_">onExit</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">const</span> maybeConfirmExit = hasChanges ? <span class="hljs-title function_">showConfirmationModal</span>() : <span class="hljs-title class_">Promise</span>.<span class="hljs-title function_">resolve</span>();
  <span class="hljs-keyword">const</span> <span class="hljs-title function_">maybeNotifySessionEnded</span> = (<span class="hljs-params"></span>) => otherSessions.<span class="hljs-property">length</span> ? <span class="hljs-title function_">notifySessionEnded</span>() : <span class="hljs-title class_">Promise</span>.<span class="hljs-title function_">resolve</span>();

  maybeConfirmExit
    .<span class="hljs-title function_">then</span>(maybeNotifySessionEnded) <span class="hljs-comment">// !important, maybeNotifySessionEnded is an arrow function</span>
    .<span class="hljs-title function_">then</span>(<span class="hljs-function">() =></span> <span class="hljs-title function_">goToHomePage</span>());
}
</code></pre>
